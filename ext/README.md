# GilgitWeb Services — Portfolio Website

Ek hi file hai: `index.html` — koi build nahi, koi install nahi.

## Live karne ka tareeka (QtyRight wala hi tareeka)
1. Apne mobile/computer ke browser mein github.com par jayen (wahan aap pehle se sign in hain)
2. New repository banayen, naam: `portfolio` — Public rakhen
3. Us repo mein "uploading an existing file" par click karke ye `index.html` file DRAG karke upload karein aur Commit karein
   (file picker se bhi ho jayegi kyunke ye sirf ek file hai)
4. vercel.com/new par jayen, ye repo Import karein, Deploy dabayen
5. Jo vercel.app link mile, wahi aap ka portfolio link hai — wahi client ko bhejna hai

## Baad mein tabdeeli
- WhatsApp number milne par Contact section mein WhatsApp button lagaya jayega — Muse ko number bhej dein.
- Name/brand tabdeel karna ho to header mein "GilgitWeb Services" tabdeel hota hai.
